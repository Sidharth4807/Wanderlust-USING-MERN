## 📌 Project Overview

**Wanderlust** is a full-stack web application inspired by Airbnb that allows
users to explore and manage property listings through a modern web interface.

The application provides secure user authentication, listing creation and
management, image uploading through Cloudinary, search and filtering
functionality, and a reviews and ratings system.

The backend is built using **Node.js and Express.js**, while **MongoDB** is
used for storing listings and reviews. The frontend is developed using
**React.js** with a responsive **TailwindCSS** interface.

---

## 🚀 Key Capabilities

- **User Authentication:** Secure user registration, login, logout, and
  session handling using JWT authentication.

- **Listing Management:** Users can create, view, update, and manage property
  listings.

- **Image Uploads:** Property images are uploaded and managed using
  Cloudinary.

- **Search & Filtering:** Users can search and filter available listings
  according to relevant property information.

- **Reviews & Ratings:** Users can add reviews and ratings to property
  listings.

- **MongoDB Integration:** Stores and retrieves users, listings, and reviews
  using MongoDB.

- **REST APIs:** Backend functionality is exposed through RESTful APIs for
  communication between frontend and backend.

- **Responsive UI:** Provides a responsive interface using TailwindCSS.

- **Real-Time Architecture:** Socket.io is included in the project's
  technology stack for real-time communication capabilities.
